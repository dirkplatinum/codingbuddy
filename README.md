# codingbuddy

## Installation

Install the package from a checkout of this repository:

```
pip install .
```

This provides the `unitconv` command.

## Usage

`unitconv` takes the name of a conversion and the value to convert, and prints
the result:

```
$ unitconv c2f 100
212.0

$ unitconv f2c 212
100.0

$ unitconv km2mi 1
0.621371192237334

$ unitconv mi2km 1
1.609344
```
